# Protocolo de Gestión de Activos Visuales (SAVI)

Para mantener la estética premium y la velocidad de carga (Performance) del sitio, las imágenes de proyectos deben seguir el siguiente estándar:

## 1. Convención de Nomenclatura
Utilizar minúsculas, guiones y descriptores claros. No usar espacios ni caracteres especiales.
- **Formato**: `[categoria]-[nombre-proyecto]-[consecutivo].[extension]`
- **Ejemplo**: `residencial-casa-navojoa-01.webp`

## 2. Especificaciones Técnicas
- **Formato Recomendado**: `.webp` (Mejor balance calidad/peso). Evitar `.png` de gran tamaño.
- **Resolución Hero**: 1920px x 1080px (mínimo).
- **Resolución Card**: 800px x 600px.
- **Optimización**: Todas las imágenes deben pasar por un compresor antes de subirse para no exceder los 300KB por activo.

## 3. Estructura de Carpetas
- `/residencial`: Vivienda de alto nivel y complejos habitacionales.
- `/comercial`: Locales, oficinas y plazas.
- `/industrial`: Naves y plantas.
- `/mision-critica`: Estaciones de servicio y proyectos de infraestructura técnica.
- `/logos`: Identidad corporativa de clientes y aliados.
- `/placeholders`: Imágenes temporales para desarrollo.

---
*Este estándar asegura que la arquitectura digital de SAVI sea tan sólida como su arquitectura física.*
